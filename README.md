# Automation Wall Detection

 
Step 1: Set the Floor plan and place the same folder as the Python code. The input image should be PNG, JPG, or JPEG.
 
Step 2: Run the Python wall detection package and make sure that both the floor plan and Python code are in the same folder
 
Step 3: After the code runs. It generates two files. Debug image file and walls.json file 
 
Step 4: Make sure you have the Blender Python script in the same folder. Once you run the Python script. It automatically generates the JSON file, Debug trace images, and FBX.
 
Step 5: Once the GLB is generated, you can import it into the Unreal project.
 
This Repo contains all the Python code and sample floor plan.
